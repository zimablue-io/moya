# Code of conduct

Be respectful. Harassment, hate, or illegal content is not welcome.

This is a household assistant. Do not use issues, PRs, or discussions to ask for help attacking systems, stealing data, or bypassing consent.

Report conduct problems with a [GitHub security advisory](https://github.com/zimablue-io/moya/security/advisories/new) if they are sensitive, or otherwise to the maintainers on the repo.
